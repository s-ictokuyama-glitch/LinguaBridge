# 授業動画での ReazonSpeech の精度改善

2026年10月25日、開発機の Ryzen 7 8840U、Windows、CPU のみで測った。
地理総合の授業動画1本（約10分、話者1人、教室ではなく収録音声）で、既定 ASR の誤りの大半が文の脱落だった。
教科用語の hotwords と `blank_penalty` を既定にし、CER は 14.08% から 8.50% に下がった。

## 測定条件

入力は 615秒の動画で、製品と同じ Silero VAD と `turn: morph` の区切りで 50 Segment、発話 583.4秒に切った。
30秒の強制分割が4回あり、10秒を超える Segment が26個あった。

参照文は人が聞き取ったものではない。ReazonSpeech の各設定と Kotoba Whisper の出力を突き合わせ、
片方にしか無い文を足し、教科用語の誤りを直して作った。ReazonSpeech の出力を下敷きにしているので、
両モデルが揃って落とした箇所は参照にも無く、ReazonSpeech に有利に偏っている可能性がある。
参照文と書き起こしは教材の複製になるため、リポジトリに入れていない。

CER は既存 `scripts/text_metrics.py` の正規化で数えた。「時」と「とき」のような表記の差も誤りになる。
用語再現は `server/asr/hotwords/geography.txt` の語が参照に現れた回数のうち、同じ Segment の出力に現れた回数である。
この語は hotwords と同じリストなので、hotwords の効果を測る指標としては甘い。CER の方を主に見る。

再現手順は次のとおり。

```
python scripts/lesson_asr_eval.py lesson.mp4 --ref ref.json --terms server/asr/hotwords/geography.txt --hotwords none --blank-penalty 0
```

## 結果

| 設定 | CER | 置換 | 脱落 | 挿入 | 用語再現 | ASR 合計時間 |
|---|---:|---:|---:|---:|---:|---:|
| 従来の既定（hotwords なし、blank_penalty 0） | 14.08% | 34 | 400 | 5 | 92/121 | 14.6〜15.0秒 |
| hotwords（score 3.0）のみ | 10.81% | 23 | 303 | 11 | 113/121 | |
| blank_penalty 1.5 のみ | 12.61% | 40 | 311 | 42 | 93/121 | |
| **新しい既定（両方）** | **8.50%** | 26 | 173 | 66 | 113/121 | 15.5〜15.7秒 |
| 参考: Kotoba Whisper v2.0（beam 5） | 23.97% | 308 | 305 | 134 | | 355.9秒 |

参照の文字数は 3,117。ASR 合計時間は 50 Segment の推論時間の和で、交互に3回ずつ測った範囲である。
Kotoba は用語を「井戸」「軽度」などと誤り、教科の字幕には向かなかった。

hotwords が直した誤りは「炊飯球→水半球」「交点→公転」「後天面→公転面」「本書士午線→本初子午線」
「正経→西経」「グリニッシュ→グリニッジ」「来た回帰線→北回帰線」など。
hotwords は誤りを直すだけでなく、ReazonSpeech が出力しなかった文も一部回復した。

blank_penalty は 0.5 / 1.0 / 1.5 / 2.0 を試した。hotwords と組み合わせた CER は 1.0 で 9.66%、1.5 で 8.50%、2.0 で 9.05% だった。
2.0 では挿入が 86 に増える。hotwords score は 1.5 / 2.0 / 3.0 / 4.0 を試し、3.0 を選んだ。
blank_penalty は hotwords の効きを弱める。既存の「原子の風→原子の数」の実音声では、blank_penalty 1.0 / 1.5 と組んだ
score 1.5 では直らず、score 2.0 / 3.0 では直った。このため設定の既定 score も 3.0 にした。

## 採用しなかった案

区間を確定する無音長 `turn.morph.check_silence_ms` を 500ms から 300ms / 200ms に縮め、短い単位で ASR を呼ぶ案は悪化した。
新しい既定の設定で CER は 11.87%（300ms）と 15.98%（200ms）だった。文脈が短くなって置換と挿入が増えた。
長い Segment を音量の谷で 6秒 / 10秒に切る案も、語の途中で切れて用語再現が下がった。
`max_active_paths` を 4 から 8 にしても改善しなかった。

## 回帰の確認

既存の拡張コーパス（TTS 34 クリップ、正解文あり）では、地理の hotwords を入れても CER は 4.37% から 3.97% に下がった。
理科の文に地理用語が紛れ込む誤りは無かった。雑音だけのクリップへの出力は 2 文字のまま変わらなかった。

## 残っている誤り

残る脱落 173 文字の多くは、Segment 冒頭の1文がまるごと消えるものだった。原因は特定していない。
収録音声の BGM や話速が関わっている可能性はあるが、推測である。教室で先生のマイクから取った音声では測っていない。
