# 画面は「校内サイン」の文法で描き、色は状態専用にする

生徒ページと先生ページは、案内表示の文法（面の色で状態を示す・装飾を置かない・太く読み違えにくい書体）で描く。色は JIS 安全色の意味に揃えて授業・接続の状態だけに使い、言語には色を割り当てない。両ページ上辺の状態帯を唯一の強い要素にする。教室で先生が授業の状態を一瞥で掴めることと、生徒が字幕を読み違えないことを、汎用的な見た目より優先したため。詳細は [画面デザインの方向性](../design/visual-direction.md)。

## Considered Options

- **放送字幕調（暗い面に大きな字幕だけ）**：読むことには特化するが、先生側の状態把握に効かない。暗い面に1色のアクセントという定番の見た目にも寄りやすい。
- **ノートと板書調（罫線・黒板の緑）**：親しみはあるが、装飾が字幕の可読性を下げ、子どもっぽく見える恐れがある。
- **言語ごとの色分け**：状態色と混ざり「1色1意味」が崩れる。言語は `EN` / `中文` / `日本語` のコード札の文字で見分ける。

## Consequences

- 赤は「記録中」専用になる。現行で赤を使っている「切断・未接続」は黄赤へ移す。
- 無音・過負荷の警告で状態帯の色を変えてはいけない。警告は帯の直下の注意板として出す。
- 帯の上の文字と記号は黒にする。JIS の表示色はどれも白文字ではコントラスト比 4.5:1 に届かないため。
- 記録中・発話中の札は色帯に載せず、帯の下の補助行に置く。帯の色が授業の状態以外と混ざらないようにするため。
- 生徒画面のダーク表示だけは帯を塗らず、状態色の文字と下辺の線で状態を示す。暗い部屋での眩しさを避けるための例外。
- 欧文書体 Atkinson Hyperlegible Next の woff2 を配布パッケージに同梱する。CDN は使わない。和文・中文は OS フォントに任せる。
- レイアウトは組み替えるが、テストと QA スクリプトが参照する要素 ID・クラス（`#cards .card` / `.text` / `.ja` など）、i18n キー、WebSocket の挙動は変えない。
