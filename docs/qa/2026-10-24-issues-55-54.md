# 参加フォームと音声再開の再検証

2026-10-24、`localServer2` の `5d2f254` で Issue #55、#54 をこの順に確認した。
両件の修正は `1cc20b3` の PR #57 に含まれていた。

## #55 の参加後表示

実 Edge、隔離した動的ポートの HTTP/WS、energy VAD、fake ASR/MT、模擬マイクで確認した。
先生と生徒は別の browser context を使用した。

生徒が参加した後、`#join-screen` は非表示、`#caption-screen` は表示になった。
先生が配信を始め、音声を送ると、生徒に字幕カードが 1 件届いた。
`web/student.css` の `#join-screen[hidden]` が機能している。

## #54 の入力途絶と再開

同じ構成で `native_speaking_after_capture_gap` 相当の手順を実行した。
音声を送ると発話中表示が点灯し、PCM 自体の送出を止めると無音警告とともに消灯した。
授業が配信中であることを確認して、同じ未確定発話への PCM 送出を再開した。
送出 binary フレームが 6 件増え、生徒の発話中表示が再点灯した。

加えて、次の既存テストは 55 件成功した。

```powershell
.venv/Scripts/python.exe -m pytest tests/unit/test_speaking.py tests/unit/test_pipeline_lifecycle.py tests/unit/test_vad.py tests/integration/test_partial.py -q
```

`test_same_open_utterance_after_capture_gap` は有効・無効設定と、有声音・無音での再開をそれぞれ確認する。
有声音での再開では通知が `[true, false, true, false]` となり、一時停止時に消灯する。
