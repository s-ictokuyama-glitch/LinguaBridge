# 画面デザインの方向性：校内サイン

2026-10-24 のグリル（17問）で合意した、生徒ページ・先生ページの視覚デザインの方向性。
実装前の決定記録であり、具体的な寸法・色値は grill-design の試作比較で詰める。
判断の要点は [ADR 0002](../adr/0002-school-signage-visual-language.md)。

## 何を解決するか

- **字幕の可読性**：教室の明るさ・距離・授業1コマ分の連続読みで疲れず、いまの発話を見失わない。
- **先生の状態把握**：授業が配信中か、マイクが入っているか、遅れていないかを一瞥で分かる。
- **ありきたりな見た目**：白い角丸カードを均等に並べた汎用 SaaS 調から離れ、このプロダクトの顔を持つ。

## 範囲

- 対象：生徒ページ（`web/index.html` / `student.css`）と先生ページ（`web/teacher.html` / `teacher.css`）。
- 接続ヘルプ（`web/connection-help.html`）は後回し。共通トークン（色・書体）を当てる程度にとどめる。

## 守る制約

- ビルド工程なしの素の HTML/CSS/JS を維持する。CDN は使わない（授業は LAN 内で完結する）。
- 欧文書体は **Atkinson Hyperlegible Next** を woff2 で1つだけ同梱する（OFL）。和文・中文は OS フォント
  （Hiragino / Noto Sans JP / Yu Gothic / Microsoft YaHei など）に任せる。
- レイアウト・情報設計まで組み替えてよい。ただし次は変えない：
  - 要素 ID とテストが参照するクラス（`#cards .card` / `.text` / `.ja`、`#session-banner`、`#start-btn` など。
    `tests/teacher_page.py`・`scripts/qa_browser.py`・`scripts/qa_native_browser.py` が依存）
  - i18n キー（`data-i18n`）
  - WebSocket の挙動
- 新しい UI 機能は足さない。明暗の切替も `prefers-color-scheme` だけで実現する。

## 世界観：校内サイン

駅や学校の案内表示の文法を借りる。状態は面の色で示し、文字は太く安定したサンセリフで、装飾は置かない。
読み違えないこと・遠くから分かることを、個性そのものにする。

### 色：1色に1つの意味

色は状態を表すためだけに使い、JIS 安全色（JIS Z 9103）の意味に揃える。

| 状態 | 色 | 対象 |
|---|---|---|
| 配信中 (live) | 緑 | 授業の状態 |
| 一時停止 (paused) | 黄 | 授業の状態 |
| 終了 (ended) | 無彩色 | 授業の状態 |
| 切断・未接続 | 黄赤 | 接続の状態 |
| 発話中 | 青 | 先生が話している途中 |
| 記録中 | 赤（● 印付き） | 授業記録が ON。**赤はこれ専用** |

- 現行は赤が「切断」と「記録中」の両方に使われている。これを解消する。
- 言語には色を割り当てない。`EN` / `中文` / `日本語` のコード札の文字で見分ける。
- 参考の色値（JIS Z 9103:2018 の表示色）：赤 `#FF4B00`、黄赤 `#F6AA00`、黄 `#F2E700`、緑 `#00B06B`、青 `#1971FF`。
  帯の上の文字色は試作で黒に決めた（下の「試作比較で決めたこと」）。

### 主役は1か所：上辺の状態帯

両ページの上辺に同じ「状態帯」を置き、授業の状態を面の色と大きな文字で示す（例：緑の帯に「配信中」）。
教室のどこから見ても状態が分かることを、このプロダクトの顔にする。ほかの要素は静かに抑える。

- 帯の色は授業・接続の状態専用。警告で上書きしない。
- 動きは状態が変わった瞬間の色の切替トランジションだけ。`prefers-reduced-motion` では切り替えを即時にする。

### 明暗

- 生徒ページ：OS の設定に追従する（`prefers-color-scheme`）。
- 先生ページ：ライト固定（プロジェクター投影を想定）。

## 生徒ページ

```
┌───────────────────────────────┐
│▶ 配信中                               │ ← 状態帯（記号と状態名だけ）
│● 記録中  発話中             [表示設定]│ ← 補助行
├───────────────────────────────┤
│  過去の発話（小さく・淡く）              │
│  過去の発話                              │
│  ひとつ前の発話                          │
│  いまの発話を大きく濃く                  │
│  原文（併記ON時）                        │
│                          [最新へ]        │
└───────────────────────────────┘
```

- **字幕は「最新を強調した流れ」**にする。最新の発話をいちばん大きく濃く、過去は段階的に控えめにする。
  均等な白カードの並びはやめる（要素の `.card` クラスは残す）。
- 状態帯には記号と状態名だけを載せ、記録中・発話中は帯の下の補助行に出す（試作で二段サインに決定）。
- 原文併記・文字サイズ・言語の切替は、補助行の右端の「表示設定」から開く下からのシートにまとめる（既存 ID はそのまま）。
- 参加画面は、参加コードを4つの升目で見せ、言語はコード札を横に並べる（下の「試作比較で決めたこと」）。

## 先生ページ

授業の段階で主役を替える。

**開始前（参加受付）**：参加案内を主役にする。QR と参加コードをプロジェクター越しに読める大きさで出し、
生徒が自分で進められるよう2つの手順として示す。

```
┌───────────────────────────────┐
│… 未開始                               │
│● 記録中                                │ ← 補助行（記録ON時だけ）
├───────────────────────────────┤
│ (1) カメラでQRを読む   (2) 参加コードを入れる │
│     [QR]                  4827           │
│                           URL            │
├───────────────────────────────┤
│ [開始]  マイク選択  入力メーター         │
└───────────────────────────────┘
```

**開始後（配信中）**：状態帯の下に状態行を置き、詳しい数値は折りたたむ。

```
┌───────────────────────────────┐
│▶ 配信中                               │ ← 状態帯
│● 記録中                                │ ← 補助行
├───────────────────────────────┤
│┃マイク入力 ▮▮▮▯ ┃生徒 28人┃遅延 0.7秒┃[一時停止][終了]┃│ ← 状態行（罫線で区切った表示板）
│┃▲ 30秒以上、マイクに音声が入っていません      ┃│ ← 注意板（表示板の下にぶら下げる）
├───────────────────────────────┤
│ 文字起こし（日本語）                     │
│ 確定した発話…                           │
│ 確定前の発話（淡く・破線）               │
│ ▸ 詳しい状況（言語内訳・遅延の内訳・キャッシュ）│ ← 折りたたみ
└───────────────────────────────┘
```

- 無音・過負荷の警告は、帯の直下に黄地・黒文字の注意板として出す。帯の色は変えない。
- 遅延の内訳（音声待ち／処理中の区別、#30）の意味づけは現行どおり保つ。見せ方だけ折りたたみへ移す。

## 試作比較で決めたこと（2026-10-24〜25）

grill-design で6回、各5案を比べて決めた。試作は [LinguaBridge 状態帯試作](https://claude.ai/artifact/22bYi8Ka8BjaoGHGKBLEyp)（非公開の Artifact）。

### 状態帯の面と文字

- 帯は状態色で塗った面にし、文字と記号は**黒**（`#000`）にする。JIS の5色はどれも白文字では
  コントラスト比 4.5:1 に届かず、黒文字なら全色で届くため（例：緑 `#00B06B` に黒で約 7.4:1）。
- 状態名の前に**形の記号**を置き、色と形の両方で状態を伝える（色覚の多様性への配慮）。

  | 状態 | 記号 |
  |---|---|
  | 配信中 | ▶ |
  | 一時停止 | ❚❚ |
  | 終了 | ■ |
  | 未開始 | … |
  | 切断・未接続 | ! |

  記号は絵文字として描かれないよう、異体字セレクタ（U+FE0E）を付けて文字として表示する。
- 寸法の目安：生徒の帯は高さ 56px・状態名 1.3rem、先生の帯は高さ 82px・状態名 2rem。

### 帯の構成：二段サイン

- 色帯に載せるのは**記号と状態名だけ**。記録中・発話中・表示設定は、帯の直下の補助行（地色は紙面よりわずかに濃い中立色）に置く。
  緑の帯の上に赤い札や青い札が重ならず、帯の色が授業の状態だけを表す。
- 記録中は赤地・発話中は青地の札に黒文字。先生画面の補助行は記録中のときだけ出す。

### 字幕の階段：連続減衰

最新の発話から離れるほど、少しずつ小さく淡くする。倍率は文字サイズ設定「中」を基準にした値。

| 最新からの距離 | 訳文の大きさ | 文字色 |
|---|---|---|
| 0（最新） | 1.6rem・太字 | 本文色 |
| 1 | 1.3rem | 二次色 |
| 2 | 1.15rem | 二次色 |
| 3 | 1.05rem | 三次色 |
| 4 以上 | 1.0rem | 三次色 |

- 原文併記が ON のときは、全発話に原文を出す。最新の発話の原文だけ一回り大きく濃くする。

### 生徒のダーク表示：反転帯

- ダーク表示では帯を塗らない。帯は暗い面のまま、記号と状態名を状態色の文字にし、下辺に状態色の太線（5px）を引く。
- そのため、ダーク表示に限っては「面の色で状態を示す」原則から外れ、文字色と線で示す。暗い部屋での眩しさを避けることを優先した。
- 状態色の文字は暗い面に対して 4.5:1 以上を保つ（緑で約 5.7:1）。

### 先生の状態行と注意板：発車標

- 状態行は、マイク入力・生徒数・遅延・操作ボタン（一時停止／終了）を、黒い枠と縦罫で区切った1本の表示板にまとめる。
  幅 700px 以下では表示板を折り返し、マイク入力と操作ボタンをそれぞれ独立した段にする（横スクロールにすると「開始」が画面外に隠れたため、実装時に改めた）。
- 配信中も遅れて来る生徒が参加できるよう、表示板に参加コードの欄を置く。
- 無音・過負荷の注意板は、表示板の下辺にぶら下げる形で出す（表示板と同じ枠線、上辺は表示板と共有）。黄地・黒文字・▲ の記号付き。
- 遅延が大きいときは、遅延の欄の地を黄にする（JIS の「黄＝注意」）。過負荷の注意板が出る前から兆候が見える。
  どの値から黄にするかは実装時に既存の過負荷判定と揃えて決める。

### 先生の参加案内：2手順

- 開始前の画面は「(1) カメラでQRを読む」「(2) 参加コードを入れる」の2列にし、黒丸の番号を付ける。
  実際に生徒が踏む順番なので番号に意味がある。
- 開始ボタン・マイク選択・入力メーターは、2手順の下に罫線で区切って置く。

### 生徒の参加画面：案内カウンター

- 参加コードは4つの升目で見せる。入力欄そのものは升目の上に透明で重ね、数字キーボード（`inputmode="numeric"`）で入力する。
  次に入る升目には下線を出す。
- 言語はコード札（`EN` / `中文` と、その言語での名前）を横に並べ、選んだ札は太枠にする。
- 見出し・説明・ラベルは、言語を選ぶ前なので3言語併記のまま（現行どおり）。

### 生徒の表示設定：下からのシート

- 補助行の「表示設定」で、画面下からシートを出す。上側は半透明の黒で覆い、字幕が透けて見える。
- シートの中身は、原文併記のチェック、文字サイズ（小・中・大の切替）、言語札の3つ。「閉じる」か、覆いを押すと閉じる。

## 次の工程

1. 決まった案で実装する。検証は既存の QA スクリプト（`scripts/qa_browser.py` ほか）で ID・クラスの互換を確認し、
   スクリーンショットで見た目を確認する。
2. 接続ヘルプに共通トークンを当てる。
