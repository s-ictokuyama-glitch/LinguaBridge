# 既定Silero経路の授業継続

既存の `morph-lesson`、`teacher-audio`、`student-continuity`、`slow-student-continuity` は、長時間入力でenergy判定器を使う。`vad-segmentation` もSileroのモデル境界を対象外にしている。出荷設定のSileroは32msごとの音声に直前64サンプルとh/c状態を加えるため、100msのenergy判定だけでは同じ経路を確認できない。

追加した [silero-lessonスキル](../../.agents/skills/silero-lesson/SKILL.md) は、この境界から既定morph、英中字幕までを扱う。記録ONでの遅着訳文保存とpartial有効時の競合も候補だったが、Sileroはすべての既定授業で通るため先に選んだ。

## 検証方法

Python 3.12.10で製品コードを直接実行し、有限入力を全列挙する。asyncio、NumPy、外部ONNXを含む経路をそのまま検査できるため、この方法を選んだ。TLA+やSMTによる証明ではなく、任意長の入力や全イベント順序を保証するものではない。

`silero_contract.py` はONNX sessionだけを代役にする。期待値は製品内部の状態から取らず、入力PCMと代役が前回返したh/cの控えから求める。PCM正規化、入力576要素、前回末尾64要素、h/cの継続とreset、確率の厳密な閾値比較を照合する。

`silero_lesson.py` は受信PCMを独立に512サンプルずつ分けて台帳へ積み、実 `SileroVAD` からONNXへ届く全フレームを比較する。代役の確率は非零PCMなら0.9、零なら0.1。ASRは音声のIDから日本語を返し、MTは言語と日本語を返す。期待字幕は音声入力計画から作る。実際のASR結果や送信件数だけから期待値を作らない。配信は実 `ClientSender` を通し、制御Socketの `send_json` 完了時に記録する。

## 全列挙と固定ケース

| 検査 | 境界 |
|---|---|
| Silero契約 | 零・符号境界・末尾印・resetの4操作、長さ0〜4の341列。各列末尾に追加入力。計1,280呼出し |
| paddingと切り詰め | 0、1、511、512、513、1024サンプルの6ケース。前後の入力も含め18呼出し |
| 授業の操作列 | 文中断片・文末・追加無音・flush・ASR完了・MT完了の6操作、長さ0〜3。512、1600、511サンプルの3送信幅で777候補、324合法列 |
| 開始と確定 | 2枚の声は拒否し3枚で開始。15枚の無音では保持し16枚でASRへ投入。31枚の無音では文中断片を保持し32枚でTurn確定 |

完了すべきFutureがない列は違法列として除外する。各操作内のPCM送信後と完了後に16回イベントループを進める。任意のawait境界を探索するものではない。各合法列の末尾で排出、flush、排出、新しい文末音声、排出を行い、後続字幕まで比較する。

授業操作の声は32フレーム、後続無音は16フレーム。追加無音は16フレーム。操作列でのflush時には512未満の端数が残っていない。端数を伴うflush、`VoiceSegmenter.reset` とSileroのreset連動、30秒以上の連続発話の強制分割は今回の範囲外。

## 50分の仮想授業

3000秒のPCMを100msごとに止めずに投入する。各構成で30,000受信チャンク、93,750 VADフレーム、1,500音声断片、1,125確定発話、英中各1,125字幕を比較する。ASRと各言語のMTの所要時間は0.2秒または0.8仮想秒。末尾の排出に10仮想秒を与え、最終flushで欠落を隠さない。

音声計画は250枚の32msフレーム、8秒の周期である。

| フレーム位置 | 入力 |
|---|---|
| 0〜31 | 文中断片 |
| 32〜47 | 無音 |
| 48〜79 | 文末。最初の断片と結合する |
| 80〜119 | 無音 |
| 120〜151 | 文中断片 |
| 152〜191 | 長無音で確定する |
| 192〜223 | 文末 |
| 224〜249 | 無音 |

期待する確定時点は周期開始から3.072、5.888、7.680秒。その8秒後までに対応する字幕数へ到達することと、最後に全文・seq・言語・順序・重複を比較する。100msと32msの周期差により受信端数をまたぐ。確認した端数の最大は448サンプル。

Sileroラッパーとmorph設定は出荷値を使う。翻訳待ち容量と再送抑制は1件へ縮める。統計間隔は3600秒で定期配信を抑制する。観測上限は音声待ち30秒、ASR待ち8件、MT待ち1件、端数511サンプル、未確定音声64フレーム、保留断片12件、履歴50件、キャッシュ512件、接続ごとの字幕記録100件、開始時タスク数+4。これは指定した入力計画での上限であり、プロセス全体のメモリー量ではない。

## 本物ONNXとの比較

`--native-only` はfaster-whisper 1.2.1、onnxruntime 1.31.0の同梱 `silero_vad_v6.onnx` を使う。新しいモデルをダウンロードしない。無音・ランプ・符号境界・440Hz波形・正負最大値の7フレームを、reset前後で合計14回入力する。製品Sileroの状態と判定を、同じsessionへの独立した直接入力と比較する。入出力の形・dtype・有限値とreset後の再現も確認する。

モデルSHA256は `4cbf549b8326f60f80f2536d9eefeb450a9abe83365a098031c89719f1be17d2`。固定の合成音声であり、日本語の音声判定精度は保証しない。代役を使う50分検証と、本物ONNXを使う14フレーム検査を混同しない。

## 破壊と復元

`--mutation-check` は一時コピーの製品ソースへ20件の破壊を1件ずつ適用する。モデル呼出し、正規化、文脈更新、h/c更新とreset、閾値、フレーム長、開始・区切りの早期化、翻訳の欠落、TurnBoundaryの欠落、排出忘れ、ワーカー停止、字幕期限超過、保持量超過、音声破棄を検出する。破壊ごとに同じ短い検査の正常対照を実行する。終了コード1、`FAIL`、指定した性質の違反が揃った場合だけ検出と認める。

本物ONNX検査の `--mutation-check` は正規化除数を32768から32767へ変更する。2枚目の入力で `_h` の不一致を検出する。どちらのコマンドも最後に元コードを再実行し、結果が破壊前と一致することを確認する。

現行コードには、この範囲で違反を検出しなかった。[基準結果](silero_lesson_baseline.json) と [本物ONNXの基準結果](silero_native_baseline.json) に実行結果と各破壊の反例を保存する。製品ファイルは変更しない。

## 保証しないもの

物理マイク、AudioWorklet、実WebSocket・LAN、教室雑音でのSilero精度、ASR・MTの意味精度、実モデルの速度、実時間50分性能、推論ハング、先生交代、生徒再接続、遅い端末、部分字幕、授業記録は今回の対象外。該当する既存スキルと併用する。実時間性能は `lesson-endurance` の実モデルコマンドで別に確認する。
