# 先生の切断と再参加をまたぐ字幕配信

`teacher-lifecycle` は無音で授業状態と先生の在籍を検査し、未完了の音声と翻訳を対象外にしている。`morph-lesson` はPCMから英中字幕までを検査するが、先生の切断と交代を含まない。この検証は両者の間を扱い、切断前に受理した音声と再参加後の音声が、接続を維持した英中生徒へ届くかを確認する。

実際の `Connection.receive` と `Connection.handling` に参加、操作、PCM、退出を与える。`Lesson`、`Roster`、`Pipeline`、energy VAD、morphの発話組立、ASRとMTの待ち行列、送信処理は製品コードを使う。Pythonの非同期実装を直接検証する既存の証明環境はないため、別のTLA+モデルへ写さず、実コードへの有限入力を列挙する。無制限の形式証明ではない。[実行手順](../../.agents/skills/teacher-continuity/SKILL.md)

## 操作列と独立した期待値

先に先生1人と英中生徒各1人を参加させ、配信を開始して継続断片を入力する。8操作 `clause`、`disconnect`、`rejoin`、`pause`、`start`、`asr`、`mt`、`paused_pcm` の長さ0〜4を全列挙する。4,681候補のうち、在籍・授業状態・未完了Futureの条件を満たす210列が合法だった。各操作後に16回のcallback処理を行う。実際のawait内部の全順序を探索するものではない。

`Expected` は、入力した断片IDと文末、停止の位置、明示的な無音境界から確定字幕を組み立てる。製品の発話組立結果や受信字幕から正解を作らない。各列の末尾でASRとMTを公平に完了させ、追加flushの前に英中の連番・言語・原文・訳文を配列で比較する。その後に再開と新しい文末発話を入力し、字幕の継続も確認する。最後のflushで切断時の確定漏れを隠さない。

PCMは16kHz PCM16の100msフレームで、非ゼロ値が断片IDを表す。ASRの代役はIDに対応する認識文を返し、MTの代役は言語と日本語を返す。ソケットの代役は送信内容と、先生交代時の指定したclose待機を記録する。

## 切断時に残る処理

| 固定ケース | 入力と観測点 |
|---|---|
| `asr_pending` | ASR実行中に切断し、認識結果の後で発話が確定することを確認する |
| `vad_open` | VADが音声区間を開いたまま切断し、残ったPCMが字幕になることを確認する |
| `morph_pending` | 継続断片を認識して発話を保留した後に切断し、字幕が確定することを確認する |
| `mt_full` | MT実行中・容量1の満杯・過負荷通知に到達し、切断と再参加後の発話を含めて照合する |
| `manual_pause` | 手動停止後に切断し、再参加後も停止を維持して開始前のPCMを除外する |
| `takeover` | 発話を保留したまま先生を交代し、旧ソケットのclose待ち中の旧先生PCMを拒否する |

同じ接続ではjoinが戻るまで次のフレームを処理しない。`takeover` は新先生登録後の旧ソケットclose待ちを1つの固定順序として扱う。旧接続の終了で保留発話が早期確定しないことも調べる。終了済みの接続へ新たな入力を送るケースではない。

## 50分の仮想入力

20仮想秒の周期を150回繰り返す。ASR実行中の切断と自動再開、手動停止中の切断と再参加、停止中のPCM、再開後の発話を含める。継続語尾と文末の結合、長い無音による確定も通す。英中生徒は接続を維持する。

100msごとに時刻を進め、ASRと各言語のMTにそれぞれ0.8仮想秒を割り当てる。発話ごとの排出待ちは挟まない。確定予定から8仮想秒以内の字幕進捗と、入力終了後10仮想秒での全件一致を要求する。これらの時間は入力計画と計算時間を固定した検査条件であり、サーバーPCの性能測定ではない。

1周期に先生不在が計1秒あるため、送信するPCMは28,500フレーム。再参加300回、受理する音声断片900件、確定字幕は英中各750件となる。音声破棄なし、ワーカー生存、停止後のタスク・接続・未処理項目の回収も判定する。

保持量の検査上限はASR音声30秒、ASR待機イベント8件、MT待機1件、morph保留12断片、履歴50件、翻訳cache512件、受信記録100件、生存task数は実行開始時+10。イベント数とtask数はこの入力計画の検査上限で、任意の入力に対する容量証明ではない。

## 破壊検出と結果

[基準結果](teacher_continuity_baseline.json) は合法210列、固定6ケース、50分入力のすべてが `PASS`。現行製品の反例は見つからなかった。製品コードの変更はない。

`--mutation-check` は各破壊の前に正常対照を実行し、`server/` の一時コピーを1箇所だけ変更する。終了コード1、`FAIL`、指定した性質の違反をすべて要求する。例外や置換失敗は `ERROR` であり、検出成功に数えない。最後に元コードで全検査を再実行して破壊前との一致を確認する。

| 一時コピーの破壊 | 検出する性質 |
|---|---|
| 切断時のflush省略、ASRより先のflush、未確定PCMの脱落 | `bilingual_delivery` |
| 自動再開の省略、手動停止でも自動再開 | `lesson_state` |
| 停止中のPCM受理、交代済み先生のPCM受理、満杯時のMT投入破棄 | `bilingual_delivery` |
| 長無音境界を遅らせる | `sustained_deadline` |
| 履歴上限の削除 | `retained_state_bound` |
| 受理する音声の破棄 | `audio_admission` |
| Pipelineの停止処理を省略 | `stop_completion` |

12破壊をすべて検出した。たとえば、継続断片を認識して保留し、先生を切断する。切断時のflushを省く破壊では、期待する英語字幕1件に対して受信は0件となり、新しい発話を加える前に検出する。

`Model the Domain` に従い入力の正解を台帳へまとめ、`Prove It Works` に従い実コードの破壊と復元を確認した。

## 保証の境界

ソケットcloseの正常完了と、列の末尾での推論の公平な完了を仮定する。全asyncio順序、無限の再接続、通信が回復しない条件の保証ではない。partialは無効、VADはenergy、morph分類器はsurfaceを使い、定期統計は3600秒間隔にして50分中は発生させない。

物理マイク、AudioWorklet、ブラウザー、実LAN、実モデルの速度と意味的な精度、推論の失敗・期限切れ、授業記録の保存は対象外。生徒の復元と新着翻訳が競合する場面は、次の検証候補とする。未完了音声を伴わない先生交代の並行処理は既存の `teacher-lifecycle` が別に扱う。
